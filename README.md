# UIN-Campus

Système de gestion académique de l'UIN.

## Description

UIN-Campus est un projet C++ destiné à la gestion académique.
Le projet utilise CMake pour la configuration et la compilation.

## Outils et versions

Les versions ci-dessous sont à compléter avec les résultats
obtenus sur la machine de développement.

- GCC (g++): à compléter
- Clang (clang++): à compléter
- CMake: à compléter
- Ninja: à compléter
- GDB: à compléter
- Git: à compléter

## Prérequis

- Un compilateur compatible avec les fonctionnalités C++23 utilisées.
- CMake 3.25 ou plus récent.
- Ninja.
- Git.
